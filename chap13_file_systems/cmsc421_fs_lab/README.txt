CMSC421 File-System Activities Code Pack

Recommended environment:
  The course Debian 12 VM
  gcc
  make
  strace

Build all C demos:
  make

Run demos:
  ./random_access_demo
  ./mmap_demo
  ./allocation_sim
  ./fat_trace
  ./bitmap_alloc
  ./tinyfs

Clean:
  make clean

Some shell activities in the walkthrough require commands such as:
  stat
  chmod
  findmnt
  df
  cat /proc/...
  strace
