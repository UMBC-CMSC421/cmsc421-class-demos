# Archived textbook fragments

These files are preserved for provenance only. They are not built by the classroom
Makefile and should not be presented as supported demos.

The numbered programs in the parent directory replace the overlapping identity,
fork, copy-on-write, exec, wait, and process-state examples. The remaining fragments
include an unfinished shell, an obsolete/incomplete kernel module, a Windows-only
example, and older pipe/shared-memory samples that lack the error handling and
cleanup required by the supported classroom set.

Keep this directory out of the live demo sequence. If one of its unique topics is
needed later, promote the concept by writing a new numbered demo in the parent
directory and adding it to the Makefile and smoke test.
